# Estruturas de Dados em Java: Práticas com ArrayList e Collections

Este repositório contém uma série de 15 exercícios práticos desenvolvidos durante o 2º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)** na **Fatec**. Os exercícios focam na manipulação de listas dinâmicas e no uso de algoritmos utilitários da linguagem Java.

## 📌 Objetivos Acadêmicos
O objetivo desta lista de exercícios foi consolidar o conhecimento em:
- Uso da classe `java.util.ArrayList` para armazenamento dinâmico de dados.
- Aplicação de métodos da classe `java.util.Collections` (ordenação, busca, estatísticas).
- Lógica de programação aplicada (filtros, contadores, loops aninhados e menus interativos).

## 🚀 Tecnologias Utilizadas
- **Linguagem**: Java 17
- **Ferramentas**: Scanner (Entrada de dados), Collections Framework.

## 📂 Guia de Exercícios

Abaixo, uma breve descrição do que foi explorado em cada arquivo:

| Exercício | Descrição | Conceito Chave |
| :--- | :--- | :--- |
| **01** | Cadastro e Ordenação de números | `Collections.sort()` |
| **02** | Inversão de lista de nomes | `Collections.reverse()` |
| **03** | Embaralhamento de dados | `Collections.shuffle()` |
| **04** | Identificação de Maior e Menor valor | `Collections.max/min()` |
| **05** | Contagem de ocorrências de um valor | `Collections.frequency()` |
| **06** | Localização de itens via Busca Binária | `Collections.binarySearch()` |
| **07** | Substituição em massa de valores | `Collections.replaceAll()` |
| **08** | Processamento de notas e cálculo de média | Loop `for-each` |
| **09** | Contagem de Números Pares e Ímpar | Operador de módulo `%` |
| **10** | Remoção seletiva de elementos | `numeros.remove()` |
| **11** | Sistema Completo (Sort, Reverse, Max, Min) | Manipulação múltipla |
| **12** | Geração de Ranking de notas | Ordenação e índices |
| **13** | Verificação de números duplicados | Loops aninhados |
| **14** | Filtro de valores (Criação de nova lista) | Filtragem de dados |
| **15** | **Sistema Integrado com Menu** | `switch-case` e `do-while` |
